# Application threat model (Step 61)

Trust boundaries for the implemented application. Remote Atlas network rules, Vercel project settings, and live secret rotation were **not** inspected.

| Boundary                       | Caller             | Sensitivity                    | Auth                                             | Validation                                    | Rate control           | Cache                                                                   | Failure                                                |
| ------------------------------ | ------------------ | ------------------------------ | ------------------------------------------------ | --------------------------------------------- | ---------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------ |
| Public pages                   | Anonymous browser  | Approved marketing copy        | None                                             | Public selectors only                         | None                   | Published catalogue is request-scoped; 15s cooldown after a failed read | Unavailable catalogue, not drafts                      |
| Enquiry Server Action          | Public form        | Name, email, message           | Origin allowlist + Turnstile server verify       | Allowlisted fields, 32 KiB budget             | Durable HMAC buckets   | `no-store` on enquiry responses                                         | Fail closed; no accepted state without a durable write |
| Admin UI                       | Staff              | Drafts, media, jobs            | Better Auth session + completed MFA + permission | Per action                                    | Session                | `force-dynamic`                                                         | Redirect on denial                                     |
| Media preview                  | Staff              | Private bytes                  | `requireAdminSession` before read                | Media id                                      | Session                | Private, not a public image cache                                       | 401/404 without the asset                              |
| Media upload                   | Staff with write   | Image bytes                    | Permission before sign/accept                    | Magic bytes; JPEG/PNG/WebP; SVG/HTML rejected | Session                | Private until published                                                 | Rejected types are not stored as public images         |
| Publish                        | Staff with publish | Public revision                | Permission + optimistic revision                 | Server fields only                            | Session                | `revalidatePath` on public URLs                                         | Stale save does not overwrite a newer revision         |
| Content / notification workers | Cron               | Job state, notification intent | `CRON_SECRET` bearer, timing-safe compare        | Bounded batch                                 | Secret required or 503 | Dynamic                                                                 | 401 without the secret                                 |
| Resend webhook                 | Provider           | Delivery events                | Signature over raw body                          | Parsed only after verify                      | Provider               | Dynamic                                                                 | Unsigned bodies rejected                               |
| `/dev/ui`                      | Local developer    | Draft specimens                | `notFound()` unless `NODE_ENV=development`       | n/a                                           | n/a                    | noindex                                                                 | Hidden in production                                   |
| Telemetry                      | —                  | —                              | —                                                | —                                             | —                      | —                                                                       | No analytics SDK in this step                          |

Editors do not receive enquiry-body access. A hidden control or layout redirect is not the authorization check; server actions and route handlers call `requirePermissionSession` / `requireAdminSession`.
