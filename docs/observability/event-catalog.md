# Event catalog (Step 62)

Browser product analytics are **disabled**. No vendor SDK is loaded. A consent decision for optional tracking is still required before any browser event can be sent. The local sink (`ANALYTICS_SINK=local`) is process memory for tests only and is not a dashboard.

Enquiry acceptance totals come from stored enquiry documents. A browser callback is not that total.

| Event                         | Purpose                                | Trigger                                           | Source of truth        | Allowed properties                                     | Dedup                                   | Consent                                              | Retention                                                  | Environment                                                   |
| ----------------------------- | -------------------------------------- | ------------------------------------------------- | ---------------------- | ------------------------------------------------------ | --------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| `service_cta_clicked`         | Which approved service CTA was used    | Click on a service-detail enquiry link            | Analytics, best effort | `serviceKey`, `routeTemplate`, `placement`, `outcome`  | Not an enquiry count                    | Required before browser send. Currently not granted. | None while disabled                                        | All environments stay disabled in the browser                 |
| `work_detail_viewed`          | A published story was opened           | Once per case-study mount                         | Analytics, best effort | `routeTemplate` `/work/[slug]`, `placement`, `outcome` | In-memory key when the local sink is on | Same                                                 | None while disabled                                        | Same                                                          |
| `contact_started`             | Someone began the form                 | First field edit. No field value.                 | Analytics, best effort | `routeTemplate`, `placement`, `outcome`                | One note per form mount when enabled    | Same                                                 | None while disabled                                        | Same                                                          |
| `contact_submit_attempted`    | Submit was pressed                     | After client validation, before the server result | Analytics, best effort | `serviceKey`, `routeTemplate`, `placement`, `outcome`  | Not an acceptance                       | Same                                                 | None while disabled                                        | Same                                                          |
| `contact_accepted`            | Server stored a new enquiry            | After a non-replay insert                         | Enquiry document       | `serviceKey`, `routeTemplate`, `placement`, `outcome`  | Replays are not recorded                | Server log is operational, not marketing             | Log line only. Local sink only when `ANALYTICS_SINK=local` | Preview must not use a production vendor. None is configured. |
| `contact_alternative_clicked` | Email, WhatsApp, or phone link clicked | Contact method link                               | Analytics, best effort | `channel`, `routeTemplate`, `placement`, `outcome`     | A click is not a sent message or a lead | Same as other browser events                         | None while disabled                                        | Same                                                          |

Unknown properties, raw URLs, query strings, admin routes, names, messages, and addresses are dropped before storage. WhatsApp or email clicks are not qualified leads. A submit attempt is not an accepted enquiry. Provider email acceptance is not delivery or a sale.

Undercount is expected from blockers and from disabled browser tracking.
